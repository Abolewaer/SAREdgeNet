# Acquisition-date candidate records

[tile_dates.csv](tile_dates.csv) links 55 local export tiles to catalog candidates. [catalog_candidates.csv](catalog_candidates.csv) lists IW/VV descending Sentinel-1 products spatially intersecting the queried extent during July–September 2022. [three_lake_candidates.csv](three_lake_candidates.csv) narrows candidates by actual lake footprints.

The query returned 367 candidate products from 2 July to 29 September 2022 (UTC). These are search results, not confirmation that all 367 were used in the historical export, and not a replacement for the earlier manuscript count of 288 scenes. The original export recipe has not been recovered; a spatial match alone cannot identify the chosen date or composite. File creation and processing timestamps are not acquisition dates.
