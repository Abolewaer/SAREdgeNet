# Three-lake HD95 supplement

`HD95_author_supplied_km.csv` transcribes the three-lake table supplied by the authors for Reviewer 2 point 35. All distances are kilometres; smaller is better. It was not recomputed during packaging. SAREdgeNet has the lowest value for Qinghai and Kokoxili; FPN has the lowest for Xiangyang.

The exact archived point sets and bidirectional percentile convention have not been recovered with this table. They must be attached before presenting it as a fully reproducible HD95 calculation. Invalidated local boundary diagnostics are excluded from this package, rather than reused to imply matching provenance. Main-lake component filtering and full-fragment evaluation answer different questions; the before/after filtering illustration remains outstanding.
